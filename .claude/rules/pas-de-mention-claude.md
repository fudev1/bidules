# Pas de mention de Claude dans les commits et les pull requests

- N'ajouter aucune mention de Claude, de Claude Code ou d'une IA dans les messages de commit, les titres et descriptions de pull request, ni les commentaires de relecture.
- Donc pas de "Generated with Claude Code", pas de "Co-Authored-By: Claude", pas d'émoji robot, pas de lien vers une session Claude.
- Le réglage `attribution` de `.claude/settings.json` retire déjà les mentions ajoutées automatiquement. Cette règle couvre aussi ce qu'on écrit soi-même.
