# Triage Labels

Les skills parlent de cinq rôles de tri. Ce fichier fait correspondre chaque rôle à l'étiquette utilisée dans les issues GitHub de ce repo.

| Label in mattpocock/skills | Label in our tracker | Sens                                          |
| -------------------------- | -------------------- | --------------------------------------------- |
| `needs-triage`             | `needs-triage`       | À évaluer par une personne du projet          |
| `needs-info`               | `needs-info`         | En attente d'informations de qui l'a ouverte  |
| `ready-for-agent`          | `ready-for-agent`    | Entièrement décrite, prête pour un agent seul |
| `ready-for-human`          | `ready-for-human`    | À faire par une personne                      |
| `wontfix`                  | `wontfix`            | Ne sera pas traitée                           |

Quand un skill nomme un rôle (par exemple « appliquer l'étiquette prête pour un agent »), utiliser l'étiquette correspondante de ce tableau.

Pour changer de vocabulaire, modifier la colonne « Label in our tracker ».
